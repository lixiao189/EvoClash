EvoClash {{ .Chart.AppVersion }} is deploying to namespace {{ .Release.Namespace }}.

Matches are pods of the StatefulSet {{ include "evoclash.server" . }} (one match per pod). The
matchmaker's leader replica keeps its size at "matches with players + buffer":

  kubectl -n {{ .Release.Namespace }} get statefulset {{ include "evoclash.server" . }} -w
  kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/component=server

{{- $max := ternary .Values.server.autoscaler.maxReplicas .Values.server.replicas .Values.server.autoscaler.enabled }}
{{- $lastPort := add (int .Values.server.basePort) (int $max) | add -1 }}
A pod's UDP port is {{ .Values.server.basePort }} + its ordinal, on the node it runs on, so open
{{ .Values.server.basePort }}-{{ $lastPort }} to players (WebTransport runs over QUIC, i.e. UDP). Pods use the
node network (hostNetwork), so the namespace must allow host networking and host ports.

Players reach a match at the node's status.hostIP unless server.publicHost is set (do that when the
node's public IP differs from the internal one).
